## Deskripsi Tugas

Tugas ini berisi dua program JavaScript yang menggunakan Array dan Function untuk mengolah data.

## Program 1: Inventaris Laboratorium
File: 01-inventaris-lab.js

Function yang digunakan:
1. tampilkanBarang() untuk menampilkan daftar barang.
2. tambahBarang() untuk menambahkan barang.
3. cariBarang() untuk mencari barang.
4. hapusBarang() untuk menghapus barang.

## Program 2: Pengolahan Nilai Praktik
File: 02-pengolahan-nilai.js

Function yang digunakan:
1. tampilkanNilai() untuk menampilkan nilai siswa.
2. hitungRataRata() untuk menghitung rata-rata.
3. hitungJumlahTuntas() untuk menghitung jumlah siswa tuntas.

## Cara Menjalankan Program

Jalankan menggunakan Node.js melalui terminal VS Code.

Soal 1:
node 01-inventaris-lab.js

Soal 2:
node 02-pengolahan-nilai.js

## Hasil Pengujian
- Inventaris berhasil menambah, mencari, dan menghapus barang.
- Pengolahan nilai berhasil menghitung rata-rata.
- Program berhasil menghitung siswa tuntas dan belum tuntas.
